# Estratégia — MD 2036

Ferramenta pedagógica para visualizar a árvore estratégica derivada da análise prospectiva.

## O que a ferramenta faz

- Carrega a árvore estratégica consolidada do Supabase;
- apresenta a sequência Missão → Objetivo → Processo → Estratégia → Iniciativa → Medida;
- mostra uma leitura pedagógica de cada nível;
- gera síntese estratégica;
- exporta JSON e CSV.

## Publicação no GitHub Pages

Crie um repositório chamado `Estrategia` e envie os arquivos:

```text
index.html
css/
js/
README.md
```

Depois ative:

```text
Settings → Pages → Deploy from a branch → main → /root
```

Link esperado:

```text
https://cenariosprospectivos.github.io/Estrategia/
```

## Observação

O exemplo pré-preenchido foi criado para apoiar o storytelling do curso e mostrar a passagem da análise prospectiva para a ação estratégica.
